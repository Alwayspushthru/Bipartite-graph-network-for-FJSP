20260531_decoupled_projection setting
Baseline: recurrent PPO + delay gating, actor+critic both use history, hist_dim=32. Single Linear(128→8) projection shared by actor local features, global mean pooling, and GRU input.
Change: replace single bottleneck with two independent projection paths.
  - Actor path: actor_j_proj / actor_m_proj / actor_pair_proj Linear(128→32), used only for per-(job,machine) logit computation.
  - Global path: global_j_proj / global_m_proj / global_pair_proj Linear(128→16), used only for mean pooling → Critic and GRU.
  - GRU input: 3×16=48 (was 24). GRU hidden: hist_dim 32→64.
  - Actor input dim: 3×32 + 2×16 + 64 = 192 (was 72). Critic input dim: 3×16 + 64 = 112 (was 56).
Hypothesis: the original 128→8 projection served three conflicting gradient sources simultaneously (policy loss for local discrimination, value loss + temporal loss for global summarization). Decoupling lets each projection specialize: actor_*_proj learns high-resolution discriminative features; global_*_proj learns distributional features that remain meaningful after mean pooling. Net parameter increase is modest (~20%), but each projection is freed from conflicting gradient interference.
Decision rule: compare greedy gaps against baseline 6.30/5.39, 15.80/0.90, 26.99/16.62/10.94/5.91; keep if overall mean improves without broad regression.

20260531_parallel_bigraph setting
Baseline: decoupled projection (actor_dim=32, global_dim=16, hist_dim=64). BiGraphLayer used sequential (Gauss-Seidel) updates: O←M computed first, updated h_j immediately, then M←O used the already-updated h_j.
Change: switch to parallel (Jacobi) updates. Both O←M and M←O aggregations are computed from the original h_j and h_m at the start of the layer; residuals are applied simultaneously after both aggregations are ready. P update still uses the post-update h_j and h_m.
Hypothesis: in the sequential design, the M←O direction sees a h_j that has already absorbed machine information, making the two directions asymmetric and coupling their gradient signals. Parallel updates decouple the two message-passing directions so each operates on the same input state, producing cleaner, more symmetric gradient flow consistent with standard GNN message passing.
Decision rule: compare greedy gaps against baseline 6.30/5.39, 15.80/0.90, 26.99/16.62/10.94/5.91; keep if overall mean improves without broad regression.

20260601_multihead_attention setting
Baseline: parallel BiGraphLayer with custom single-head attention (hand-written Q/K/V + pair-wise bias wa/wa_mo + gate).
Change: replace custom single-head attention in BiGraphLayer with nn.MultiheadAttention (num_heads=2, batch_first=True, d=128 → each head dim=64).
  - O←M: attn_om(query=h_j, key=h_m, value=h_m, key_padding_mask=machines_all_invalid)
  - M←O: attn_mo(query=h_m, key=h_j, value=h_j, key_padding_mask=jobs_all_invalid)
  - pair-wise attention bias (wa, wa_mo) removed; gate now uses h_pair.mean() as approximation.
  - Parameter count change: similar total, but Q/K/V projections are now fused and internally split per head.
Hypothesis: multi-head attention allows each head to specialize in a different relational pattern (e.g., one head tracks processing-time similarity, another tracks load balance). Two heads keep each subspace large (64-dim) to avoid overfitting on limited FJSP relational diversity. The main risk is that removing the pair-wise bias loses per-(job,machine) edge information that was previously injected into the attention score.
Decision rule: compare greedy gaps against baseline 6.30/5.39, 15.80/0.90, 26.99/16.62/10.94/5.91; keep if overall mean improves without broad regression.

20260601_bigraph_attention setting
Baseline: parallel BiGraphLayer with generic nn.MultiheadAttention (num_heads=2, pair-wise bias and gate removed).
Change: replace nn.MultiheadAttention with custom BiGraphAttention module that restores the two FJSP-specific mechanisms in a multi-head formulation.
  - pair-wise attention bias: wa(h_pair) → [B, Nq, Nk, num_heads] → added to scores per head (was single scalar in original).
  - pair-wise gate: Wg applied to attention-weighted pair context h_pair_ctx = Σ_k α_k * h_pair_k (was exact per-pair gate in original; now attention-weighted mean, preserves pair selectivity without O(J×M×d) expansion during gate computation).
  - output projection Wo added (standard multi-head practice).
  - num_heads=2, head_dim=64, d=128. Interface: BiGraphAttention(query_feat, key_feat, h_pair, mask).
  - M←O direction passes h_pair.transpose(1,2) so machines are query dimension.
Hypothesis: the regression in the previous nn.MultiheadAttention runs was caused by removing the pair-wise attention bias and degrading the gate to a uniform mean. Restoring both in a multi-head formulation should recover at least single-head performance while retaining the capacity for heads to specialize on different relational aspects of the FJSP graph.
Decision rule: compare greedy gaps against baseline 6.30/5.39, 15.80/0.90, 26.99/16.62/10.94/5.91; keep if overall mean improves without broad regression.
