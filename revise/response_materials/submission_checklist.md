# Revision Submission Checklist

- [ ] Every editor and reviewer comment has a stable ID.
- [ ] Every claimed experiment has a recorded configuration, seed, checkpoint, and raw result path.
- [ ] Every reported number has been independently checked against the raw result.
- [ ] Every response identifies the corresponding manuscript section, page, and line range.
- [ ] Revised manuscript passages quoted in the response letter are formatted consistently.
- [ ] The marked manuscript and clean manuscript contain the same substantive revisions.
- [ ] Abstract, Introduction, Results, and Conclusion make claims consistent with the final evidence.
- [ ] No `AUTHOR_INPUT_NEEDED` or `PENDING_EXPERIMENT` placeholder remains.
- [ ] Figures, tables, captions, and cross-references have been checked.
- [ ] The final response maintains a professional and non-defensive tone.
